    规则书
    • 一行一词条；空行不校验。
    • 分隔符：空格 + · ，、，用于切分词条多个片段。
    • 每段须词库构成，否则标红（E101 未收录片段）。
    • 整行无匹配 → E102 未收录词条。
    • 示例：杀 闪 → 片段「杀」「闪」须分别收录。
    • [ ] = 可省略项：北京[大学] 匹配 北京 或 北京大学。
    • 省略后仍须校验；空 [] 有提示（E203）。
    • 方括号须成对（E201 未闭合 / E202 多余），全角 ［ ］ 等价。
    • 示例：北京[大学] 若「大学」未收录，省略形式 北京 通过，完整形式标 E101。
    • “ ” = 省略值：无需收录，不报 E101/E102。
    • 引号须成对（E401 未闭合）；空 “” 有提示（W404）。
    • 省略后仍须校验（同 [ ]）。
    • 示例：张“飞” 匹配 张飞，「飞」无需收录。
    • { } 内用 | 分隔，二选一：{杀|闪} 匹配 杀 或 闪。
    • 空选项（E204）、组外 |（E207）会被诊断。
    • 重复选项（W303）、单选项（W305）警告。
    • 示例：{杀|杀} → W303 重复；{|杀} → E204 空选项。
    • // 行内注释：// 后内容不校验。
    • 行首 # 整行注释。
    • 示例：杀 // 这是注释 → 只校验「杀」。
    符号按《国殇规则集》第八章识别，\ 可转义特殊符号。
    • 全角/半角符号等价：，/,、· 等。
    • 无效转义（W405）、悬空转义（W406）会被诊断。
    词库词条可含槽位，一条匹配多段文字。
    • ……：中段接受词库覆盖内容（连搭配/模式/括号内）或留空；须成对书写。
    • .A=数字 .B=大写 .C=中文 .D=小写 .E=符号，.AC=中文数字（如“十二”）。
    • （a/b/c）：/ 分隔，其一必填；选项可为 ……。
    • or/and/not：槽位逻辑组合，空格分隔。
    • 只单中段槽，槽位间不夹字面量。
    • 示例：一…… 匹配「一」开头中段任意词；（a/b） 匹配 a 或 b。
    • 智能分词：动态规划切分，优先长词；数字豁免。
    • 整词匹配：每段须与词库一致（未收录标 E101）。
    • 数字豁免（W306）：数字 / 中文数字 / X 不强制收录。
    • 词库为空时暂停校验。
    取消勾选即关闭该规则。代码含义：E=错误（红）、W=警告（黄）、P=格式、ED=构建词条。
    • ED 构建词条规则（词条必须中文 ED101、禁用数字 ED102、超长 ED103）在编辑器构建词条时生效。
    插件 rules 数组可写自定义规则（逐行 test）。
    • test 表达式变量：line=当前行、idx=行索引、ln=行号、text=全文。
    • 返回 true 触发规则，返回字符串覆盖默认消息。
    {
  "id": "R001",                       // 规则 id（不能与内置规则 / 其他插件冲突）
  "name": "检测敏感词",                // 规则名（诊断显示）
  "level": "warn",                    // "error" 或"warn"
  "message": "第 {ln} 行含敏感词",     // 支持 {ln} 行号、{idx} 行索引
  "test": "line.includes('敏感')",    // JS 表达式：line=当前行, idx=行索引, ln=行号, text=全文
  "enabled": true                     // 可选，默认启用
}
    导入即生效；可关闭「插件适用规则」。
    • 「设置」可开关自动换行（默认开）。
    • 每行 50 字宽，超过自动折行（词条不拆分）。
    • 折行行号对齐词条首行，点行号选中词条。
    • 关闭时超长词条横向滚动。
    • 与 P102 超长行（>120 字）提示联动。
    插件为 .json 或 .zip（内含 mod.json + 资源）。必填 id、name。
    {
  "id": "my-mod",          // 必填：唯一 id（不能与内置/其他插件冲突）
  "name": "我的插件",        // 必填：显示名
  "version": "1.0.0",      // 可选：版本
  "author": "作者",        // 可选
  "description": "说明",    // 可选
  "enabled": true,         // 可选：默认启用
  "lexicon": ["词条1"],    // 可选：扩充词库词条
  "rules": [],             // 可选：自定义校验规则（见「插件规则格式」）
  "output": [],            // 可选：输出处理
  "scripts": [],           // 可选：脚本
  "outputPython": "..."    // 可选：Python 输出
}
    .zip 可内置资源（字体/数据），通过 mod-sw.js 读取；导入即生效。
    • 逐行输入：每行一词条，空行不校验；需先导入词库或添加词条（词库为空暂停校验）。
    • 分隔：空格 + · ，、 切分多个片段，每段须词库构成（E101）。
    • 可省略：[ ] 内容可省略，如 北京[大学] 匹配 北京 或 北京大学。
    • 省略值：“ ” 内容无需收录，如 张“飞” 匹配 张飞。
    • 选项组：{ } 内 | 分隔二选一，如 {杀|闪} 匹配 杀 或 闪。
    • 槽位：词条可含 ……、.A~.E、（a/b） 匹配多段文字（见「词库词条模式语法」）。
    • 注释：// 行内、行首 # 整行注释，不校验。
    • 实时诊断：输入时立即标出未收录（E101）、重复（W301）、非中文（ED101）等。
