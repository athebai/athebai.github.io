    词条写法

    北京大学一个词条，须与词库一致（整词匹配模式）
    北京 大学用空格、+、·、，、、分隔多个词条
    北京[大学][ ] 为可省略项：可匹配“北京”或“北京大学”
    “北京大学”“ ” 内的值为省略值：内容无需收录于词库（不报未收录），作为可省略项参与匹配
    {大学|学院}{ } 为选项组：按 | 二选一
    【北京大学】【 】 引用牌名：内容不参与词条校验
    北京\，大学\ 为转义符：后面的符号按普通文字处理
    将他们的匹配词库里的模式词条 将……的：…… 中段接受词库规则覆盖的内容（词条可连续搭配 / 其他模式词条匹配 / （）【】 成对符号闭合内文本不参与校验）或留空——输入内容未报错便不会报错
    第1章 / 第章匹配 第.A章：.A–.E 为一或多个同类字符（可空）
    .A=数字　.B=大写英文　.C=中文　.D=小写英文　.E=符号　.AC=中文数字（如“十二”）
    将己方目标匹配 将（己方/敌方）目标：（a/b/c） 为 / 分隔的通联词条，其一必填
    abc / 123匹配 .C or .D：or/and/not 组合槽位（not .C 表示非中文）
    // 注释 / # 注释注释不参与校验

    符号与转义

    校验模式

    • 智能分词：自动按词库切分输入，未匹配到的字标红，适合连续中文。
    • 整词匹配：以分隔符为单位，每个词条必须与词库完全一致。

    词库 TXT 格式

    • 每行一个词条；词条　注释（用 Tab 或 | 分隔）可附加注释。
    • 以 # 或 // 开头的行视为注释，自动忽略。
    • 词条里写 …… 即为模式词条（如 将……的）：“……”中段接受词库规则覆盖的内容（词库词条可连续搭配，或被其他模式词条覆盖的合法内容，或 （）【】 成对符号闭合内文本——闭合内不参与校验）或留空——即输入内容未报错便不会报错，这类词条在词库面板标有“通配”。通配「……」须两个省略号成对书写；单个「…」按普通文字处理。
    • 词条里还可写 .A–.E（一或多个同类字符，可空）、.AC（一或多个中文数字，可空）、（a/b/c）（通配，其一必填）、or/and/not（槽位间组合），同样标有“模式”。
    • 只支持单个中段槽位：槽位前后各一段字面量；第.A章 or .B 这类“槽位夹字面量”不合法，应拆成两条词条。
    • 词条本身不能包含空格，or/and/not 两侧的空格除外。
    • 导入的每个 TXT 会成为独立分组（以文件名命名）；也可在词库面板底部点「新建词库」创建空白分组（双击名称可重命名）。分组可勾选「关联」——关联的分组自动合并去重，重复相同的词条只保留一份（可在规则书 → 词库行为中关闭「自动删除相同词条」，关闭后关联分组保留重复词条、仅合并显示）。手动添加的词条进入当前选中的分组。

    规则书
    一、词条与分隔符
    • 一行 = 一条词条记录；空行不参与校验。
    • 分隔符：空格、+、·、，、、（全角符号自动识别）。
    • 分隔后的每一段文字都必须能由词库构成，否则标红。
    二、可省略项 [ ]
    • [ ] 中的内容是可省略值：北京[大学] 同时匹配“北京”与“北京大学”。
    • 省略后剩余部分仍须通过校验；[] 为空、或整行只有 [ ] 会给出提示。
    • 方括号必须成对出现，全角 ［ ］ 自动等价。
    三、省略值 “”
    • “ ” 内的值是省略值：内容无需收录于词库（不报未收录 E101/E102），作为可省略项参与匹配，如 “科技公司”。
    • 与 [ ] 类似，但省略值本身不再要求收录；引号必须成对出现，空引号 “” 会提示。
    • 省略后剩余部分仍须通过校验；整行只有 “ ” 会给出提示（同 [ ]）。
    四、选项组 { }
    • { } 内用 | 分隔多个选项，整组二选一：{大学|学院}。
    • 空选项、重复选项、“|”写在组外都会被诊断。
    五、注释
    • // 之后、或行首 # 之后的内容是注释，不参与校验。
    六、符号规范
    下列符号按《国殇规则集》第八章识别并高亮；把 \ 写在符号前可将其转义为普通文字（如 \，，\\ 表示反斜杠本身）。
    词库词条模式语法
    在词库词条（不是正文）里可使用槽位，让一条词条匹配多段文字；词库面板中槽位已着色标出。
    • ……：中段接受词库规则覆盖的内容（词库词条可连续搭配，或被 （a/b/c）、.A–.E 等模式词条覆盖的合法内容，或 （）【】 成对符号闭合内文本——闭合内不参与校验），或留空——即输入内容未报错便不会报错。如 将……的 匹配 将师范的（若“师范”在词库）、将北京大学的（“北京大学”=“北京”+“大学”搭配）、将【无】的（“无”在【】内不参与校验）与 将的。须两个省略号「…」成对书写；单个「…」是普通文字（如符号省略号）。
    • .A–.E：一或多个同类字符，可空。.A=数字，.B=大写英文，.C=中文，.D=小写英文，.E=符号。.AC：一或多个中文数字（零一二三…十百千万亿两…），可空，如 第.AC章 匹配 第十二章。
    • （a/b/c）：通配词条，/ 分隔的选项之一必填；各选项也可以是 ……（此时该分支匹配词库规则覆盖的内容）。如 将（己方/敌方）目标 匹配 将己方目标 / 将敌方目标；将（你/……）的 匹配 将你的 / 将北京大学的（“……”=“北京大学”）。
    • or/and/not：槽位间逻辑组合，需用空格分隔。如 .C or .D（中文或小写）、not .C（非中文）、.A and not .C（数字且非中文）。
    • 只支持单个中段槽位：槽位（含 or/and/not 组合）前后各一段字面量，槽位之间不允许夹字面量；第.A章 or .B 不合法，应拆成 第.A章 与 .B 两条词条。
    七、校验模式
    • 智能分词：按词库动态规划切分连续文字，优先保留更长的词，未覆盖的字合并标红；数字 / X / 中文数字自动豁免。
    • 整词匹配：以分隔符为单位，每段必须与词库完全一致。
    • 词库为空时暂停词条校验，并在诊断面板提示。
    八、诊断代码与开关
    取消勾选可关闭对应规则（同时不再高亮、不再计入诊断）。
    设置
    插件（Mod）
       支持 .json / .zip 插件：可携带词条扩充（并入词库识别，不标未收录）与自定义校验规则（按行检测，输出错误/警告）；.zip 包可内置 Pyodide 等随包资源，导入后自包含运行。也可将 .zip / .json 拖到词库面板或此处导入。
    字体
      支持 TTF / OTF / TTC / WOFF / WOFF2，可多选。导入的字体保存在浏览器中，作用于整个应用；内置字体已内嵌进应用（OFL 开源许可）。
    遮暗  模糊 
    面板不透明  默认 100 = 主题默认；调低后自动叠加毛玻璃模糊，配合背景图最通透。
    放射柔度  50 液态玻璃「清晰窗口」：模糊从对话框边缘向外放射过渡的柔和度（0 锐利 / 100 极柔和）。
    字体描边  关 全局文字描边（0 关–100 最强）：按当前主题文字色自动取对比描边色，任何背景下文字都更清晰。
